What Are Plugins in Jenkins?

- Plugins are add-ons that extend Jenkins' core functionality.

They help Jenkins integrate with tools like:
1. GitHub, GitLab
2. Docker
3. Slack
4. Maven, Gradle
5. JIRA
6.Kubernetes

Basically, if Jenkins needs to do anything beyond basic build automation, 
there's probably a plugin for it.


Why Are Plugins Important?

- Without plugins, Jenkins is just a basic automation server. 

Plugins let us:
1. Connect to source code repositories (e.g., Git plugin)
2. Add build tools (e.g., Maven, Gradle plugin)
3. Send notifications (e.g., Email, Slack)
4. Use containers (e.g., Docker plugin)
5. Define complex pipelines (Pipeline plugin
