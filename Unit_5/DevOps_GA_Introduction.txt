GitHub Actions is a CI/CD (Continuous Integration & Continuous Deployment) platform that 
allows you to automate workflows directly inside your GitHub repository.

It helps in:
1. Building code 
2. Running tests 
3. Deploying applications 
4. Automating repetitive development tasks 

Analogy:
Think of GitHub Actions like a smart assistant that automatically performs tasks (like 
testing or deployment) whenever something happens in your repository.

What is a Workflow?
1. A workflow is an automated process defined in a YAML file.
2. Stored inside .github/workflows/ 
3. Contains one or more jobs 
4. Each job has steps (commands/actions)

Components of Workflow
1. Event (on) → When to run 
2. Jobs → What to do 
3. Steps → How to do 
4. Actions → Predefined reusable tasks
